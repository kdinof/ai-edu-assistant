# AI Content Pipeline

AI-пайплайн для автоматизации создания образовательных курсов — от идеи до готового контента.

## Требования

- [Claude Code](https://docs.anthropic.com/en/docs/claude-code) (CLI)

## Установка

Клонируй репозиторий, перейди в папку проекта и запусти Claude Code:

```bash
cd projects/active/ai-edu-assistant
claude
```

## Запуск

```bash
claude
```

Затем используй одну из команд:

| Команда | Что делает |
|---------|-----------|
| `/pipeline` | Запуск или возобновление полного pipeline (определяет текущий этап автоматически) |
| `/bootstrap` | Только Stage 01 — интерактивный опросник для нового курса |
| `/course-structure` | Только Stage 03 — генерация структуры курса из PRD |

## Как работает Pipeline

```
Идея → Bootstrap (+референсы) → PRD → [Human Review] →
→ Структура → [Методолог Review] →
→ Content Generation → [Validation] → Тесты → Lesson Summaries → Перевод (опционально)
```

### Этапы

| # | Stage | Что происходит | Human Gate |
|---|-------|---------------|------------|
| 01 | **Bootstrap** | Опросник (тема, аудитория, learning outcomes, финальный артефакт, инструменты) + обязательная загрузка референсных материалов — курс строится только на них | — |
| 02 | **PRD** | Синтез bootstrap + референсов в Product Requirements Document | Gate 1: PRD Review |
| 03 | **Structure** | Детальная структура курса: модули (15-30 мин), уроки (5-10 мин), практика | Gate 2: Методолог Review |
| 04 | **Content Generation** | Контент уроков: видео-скрипт + текст + ключевые выводы | — |
| 05 | **Tests** | Квиз-вопросы + практические задания на модуль | — |
| 06 | **Lesson Summaries** | Текстовые описания уроков (рядом с уроком) | — |
| 07 | **Translation** | Перевод на целевые языки курса с сохранением markdown-структуры (опционально) | — |

### Human Gates

Pipeline останавливается в двух точках для ревью:
- **Gate 1 — после Stage 02 (PRD)** — проверка learning outcomes, скоупа, позиционирования
- **Gate 2 — после Stage 03 (Structure)** — проверка структуры методологом

Варианты решения: Утвердить / Правки / Отклонить.

### Состояние Pipeline

Прогресс сохраняется в `courses/{slug}/pipeline-state.json`. При повторном запуске `/pipeline` — продолжает с последнего этапа.

## Обновление проекта

Когда на GitHub выходит новая версия pipeline, вам нужно обновить свою копию. Ваши курсы и данные при этом сохранятся.

### Если вы клонировали проект через git (рекомендуется)

Откройте Claude Code в папке проекта и напишите:

```
Обнови проект из GitHub. Если будут конфликты в courses/ — оставь мои локальные версии.
```

Claude выполнит `git pull` и разрешит возможные конфликты.

### Если вы скачали проект как ZIP-архив

Первый раз нужно подключить git. Откройте Claude Code в папке проекта и напишите:

```
Подключи этот проект к git-репозиторию https://github.com/kdinof/ai-edu-assistant.git
Сохрани мои локальные изменения.
```

Claude настроит git и подтянет обновления. После этого для будущих обновлений достаточно:

```
Обнови проект из GitHub
```

### Что обновляется, а что нет

| Папка | Обновляется? | Почему |
|-------|-------------|--------|
| `.claude/` | Да | Шаблоны, скрипты, команды pipeline |
| `courses/` | Частично | Пример-курсы из репозитория обновятся, ваши новые курсы не затрагиваются |

## Структура проекта

```
.claude/
├── commands/                    # Slash-команды (/pipeline, /bootstrap, ...)
├── skills/
│   ├── content-pipeline/        # Оркестратор pipeline
│   │   ├── stages/              # Инструкции для каждого этапа
│   │   ├── templates/           # Шаблоны артефактов
│   │   ├── references/          # Контракты вход/выход, quality gates
│   │   └── knowledge-base/      # Как добавлять reference-курсы
│   └── fact-check/              # Верификация технических утверждений

courses/                         # Результаты pipeline
└── {slug}/                      # Папка курса
    ├── pipeline-state.json
    ├── references/              # Загруженные пользователем материалы (обязательно)
    ├── 01-bootstrap.md
    ├── 02-prd.md
    ├── 03-structure.md
    ├── 04-content/
    ├── 05-tests/
    └── 07-translations/
```
