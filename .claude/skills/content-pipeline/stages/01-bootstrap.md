# Stage 01: Bootstrap

## Задача

Собрать всю необходимую информацию об идее курса через интерактивный диалог с пользователем. Результат — заполненный опросник `01-bootstrap.md`.

## Инструкции

### 0. Roadmap

Покажи Roadmap (формат из SKILL.md) с `🔄 01 Bootstrap` как текущим этапом.

### 1. Начало

Прочитай шаблон: `.claude/skills/content-pipeline/templates/bootstrap-questionnaire.md`

Если пользователь уже предоставил идею курса — извлеки из неё максимум информации и заполни то, что можно.

### 2. Интерактивный опрос

Задавай вопросы **по одному блоку за раз**, не все сразу. Используй **AskUserQuestion** для каждого блока.

**Задачи опроса:**

- [ ] 1. **Тема и описание** — Уточни название и суть курса
- [ ] 2. **Целевая аудитория** — Кто будет проходить? Уровень? Что уже знает?
- [ ] 3. **Learning Outcomes** — Что студент сможет делать после курса? (помоги сформулировать конкретно)
- [ ] 4. **Параметры** — Длительность, количество модулей. Формат не спрашивай — по умолчанию текст + интерактивные HTML-материалы
- [ ] 5. **Дополнительно** — Эксперт, ограничения, связь с другими курсами

### 3. Помощь пользователю

- Если пользователь затрудняется с Learning Outcomes — предложи 3-4 варианта на основе темы
- Если не уверен в длительности — предложи диапазон на основе темы

### 4. Сохранение

Заполни шаблон `bootstrap-questionnaire.md` ответами пользователя. Сохрани как:

```
courses/{slug}/01-bootstrap.md
```

### 5. Референсные материалы (обязательно)

Курс строится ТОЛЬКО на материалах, загруженных пользователем — референсы обязательны, этап не может завершиться без них.

**5a. Файлы**

Создай (если не создана) папку `courses/{slug}/references/`.

Используй **AskUserQuestion**:
- question: "Референсы обязательны для продолжения. Положите в папку `courses/{slug}/references/` ваши материалы по теме курса — наработки, статьи, документы, черновики, презентации. Это единственный источник контента для курса. Когда файлы загружены — подтвердите."
- options: `["Файлы добавлены, продолжить", "У меня нет файлов, только ссылки"]`

**5b. Ссылки**

Используй **AskUserQuestion** (freeform, без options):
- question: "Есть ли ссылки на статьи, документацию или ресурсы по теме курса? Отправьте по одной на строку. Если нет — напишите 'нет'."

Если пользователь предоставил ссылки — сохрани в `courses/{slug}/references/links.md`:

```markdown
# Reference Links

- {url1}
- {url2}
```

**5c. Проверка референсов (блокирующая)**

1. Через Glob проверь файлы в `courses/{slug}/references/` (исключая `links.md`)
2. Посчитай количество ссылок в `links.md` (если создан)
3. Если файлов нет И ссылок нет — pipeline **не может продолжиться**:
   - Объясни пользователю, что референсы обязательны — курс строится только на загруженных материалах, других источников контента у pipeline нет
   - Вернись к шагу 5a и жди, пока пользователь добавит хотя бы один файл или ссылку
4. Как только есть хотя бы один референс (файл или ссылка), обнови `pipeline-state.json`:

```json
{
  "has_references": true,
  "references": {
    "files_count": 3,
    "links_count": 2
  }
}
```

### 6. Обновление state

```json
{
  "stages": {
    "01-bootstrap": {
      "status": "completed",
      "completed_at": "{ISO datetime}"
    }
  },
  "current_stage": "02-prd"
}
```

### 7. Переход

Покажи Roadmap с `✅ 01 Bootstrap` и `⬜ 02 PRD` как следующим.

Используй **AskUserQuestion**:
- question: "Bootstrap завершён, референсы загружены. Перейти к PRD?"
- options: `["Продолжить к PRD", "Остановиться"]`

## Quality Checklist

Перед сохранением проверь:
- [ ] Все поля опросника заполнены
- [ ] ЦА описана конкретно
- [ ] Learning outcomes измеримы
- [ ] Длительность реалистична (1-3 часа)
- [ ] Референсы загружены, `has_references: true` в pipeline-state.json
