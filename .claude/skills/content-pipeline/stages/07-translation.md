# Stage 07: Translation (опционально)

> Этот стейдж запускается, только если курсу требуется перевод на другие языки.

## Задача

Перевести все материалы курса с основного языка на целевые языки курса. Целевые языки спроси у пользователя при запуске стейджа через **AskUserQuestion** (если он не указал их сам). Если перевод не нужен — стейдж пропускается.

## Вход

- Все файлы stages 03-06
- Целевые языки курса (от пользователя при запуске стейджа)

## Выход

- `07-translations/{lang}/` — зеркальная структура материалов курса на целевом языке (по одной папке на каждый целевой язык)

## Подход

1. Перевод с сохранением markdown-структуры (заголовки, списки, таблицы, нумерация)
2. Техтермины: транслитерация/локальный термин + оригинал в скобках (например, для узбекского: "dasturlash (программирование)")
3. Сохранение форматирования, ссылок, нумерации уроков и модулей
4. Порядок: структура (03) → контент (04) → тесты (05) → lesson summaries (06)

## Выбор переводчика

- Если целевой язык — **узбекский**: используй агента `uz-content-translator` (специализированная память по терминологии и стилю).
- Для **других целевых языков**: используй general-purpose агента-переводчика с теми же правилами (сохранение структуры, транслитерация техтерминов, порядок стейджей), запуская отдельный субагент на язык/модуль параллельно — по аналогии с `uz-content-translator`.

## Quality Checklist

- [ ] Целевые языки подтверждены пользователем (или стейдж пропущен, если перевод не требуется)
- [ ] Все stages 03-06 переведены для каждого целевого языка
- [ ] Markdown-структура и форматирование сохранены
- [ ] Техтермины даны с оригиналом в скобках
- [ ] Результат сохранён в `07-translations/{lang}/`
